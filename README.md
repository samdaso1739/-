# 🤖 매일매일 AI 코딩 챌린지 (PWA & LLM 기반 학습 앱)

> **"매일 아침, AI가 배달해 주는 단 하나의 코딩 문제!"**
> 본 프로젝트는 최신 웹 기술인 **PWA(Progressive Web App)**와 **Google Gemini API**를 융합하여 만든 서버리스(Serverless) 기반 모바일 친화적 코딩 학습 플랫폼입니다. 복잡한 백엔드 서버 없이 HTML5와 JavaScript 기술만으로 스마트폰에 즉시 설치하여 매일 새로운 문제를 풀고 학습 습관을 형성할 수 있습니다.

---

## 👥 팀원 및 역할 분담 (교양 O조)
* **팀장 / AI 연동 & 데이터 설계:** OOO (JavaScript 기반 Gemini API 비동기 제어, 구조화된 JSON 데이터 파싱 및 LocalStorage 구조 설계 담당)
* **프론트엔드 UI & PWA:** OOO (HTML5/Tailwind CSS 반응형 레이아웃 디자인, 웹 앱 매니페스트 및 서비스 워커 등록을 통한 앱 설치 기능 담당)
* **기획 & 프롬프트 엔지니어링:** OOO (학습 시나리오 설계, `gemini-2.5-flash` 맞춤형 파이썬 출제 프롬프트 고도화 및 데이터 예외 처리 테스트 담당)
* **자료 제작 & 발표:** OOO (실제 모바일 구동/설치 화면 캡처, GitHub Pages 배포 시연 준비 및 프로젝트 성과 발표 담당)

---

## 🛠️ 기술 스택 (Tech Stack)
* **Frontend:** HTML5, JavaScript (ES6+ Fetch API), Tailwind CSS (반응형 모바일 퍼스트 디자인)
* **AI Engine:** Google Gemini 2.5 Flash (`v1` 표준 엔드포인트 활용 및 JSON 구조화 출력 적용)
* **Data Storage:** Web LocalStorage (서버가 필요 없는 브라우저 내장 데이터베이스)
* **App Deploy & PWA:** GitHub Pages (HTTPS 자동 적용 인프라), Web App Manifest, Service Worker

---

## 📐 시스템 아키텍처 (작동 원리)
1. **유저**가 QR코드나 링크를 통해 앱(PWA)에 접속한 뒤 홈 화면에 추가하여 단독 앱 형태로 실행합니다.
2. **프론트엔드(JS)**가 백엔드 서버를 거치지 않고 구글 **Gemini 2.5 Flash API**를 직접 호출(`fetch`)합니다.
3. AI는 정교하게 설계된 프롬프트에 따라 난이도가 조절된 파이썬 기초 문제를 **JSON 데이터** 형태로 실시간 생성하여 반환합니다.
4. 브라우저가 JSON 데이터를 파싱하여 화면에 깔끔한 **4지선다형 UI**로 동적 렌더링합니다.
5. 유저가 정답을 맞히거나 틀리면 해당 날짜의 결과가 기기 내부 **LocalStorage**에 저장되며, **실시간 캘린더**와 **누적 정답률 통계** 대시보드가 즉각 갱신됩니다.

## 📺 주요 기능 및 화면 UI

### 1. 📱 서버리스 기반 PWA 원클릭 설치
* `manifest.json`과 서비스 워커 기술을 적용하여, 앱스토어 다운로드 없이 브라우저의 "홈 화면에 추가" 버튼 하나로 스마트폰에 독립된 앱처럼 설치됩니다.
* 주소창이 숨겨진 **단독 앱 모드(Standalone)**를 지원하여 완벽한 모바일 네이티브 앱 경험을 제공합니다.

### 2. ⚡ 반응형 모바일 퍼스트 UI
* Tailwind CSS의 유연한 그리드와 뷰포트 최싱 기술을 활용하여 스마트폰 화면에 최적화된 직관적이고 쾌적한 학습 환경을 제공합니다.

### 3. 📅 학습 트래킹 캘린더 & 통계
* 문제를 푼 날은 초록색 정답 배지(🟢), 틀린 날은 오답 배지(🔴)가 달력에 마킹되어 이번 달 누적 학습 현황을 시각적으로 모니터링할 수 있습니다.
* 전체 풀이 횟수 대비 정답률(%) 대시보드를 제공하여 학습 동기를 부여합니다.

## 🏃‍♂️ 실행 및 배포 방법 (How to Run & Deploy)

### 1) 로컬 실행
* 별도의 서버 설치(Python, Node.js 등)가 전혀 필요하지 않습니다. 
* 다운로드한 `index.html` 파일을 크롬, 사파리 등 브라우저에 **더블 클릭**하여 실행하거나, VS Code의 `Live Server` 확장 프로그램을 통해 즉시 구동할 수 있습니다.

### 2) 웹 호스팅 배포 (PWA 활성화)
* PWA 기능을 작동시키기 위해서는 보안 연결(HTTPS)이 필수적입니다.
* 정적 웹 호스팅 서비스인 **GitHub Pages** 또는 **Vercel**에 해당 HTML 프로젝트 폴더를 업로드하면 무료로 즉시 배포 및 실시간 스마트폰 시연이 가능합니다.
