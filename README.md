# 💻 AI 코딩 미션 & 오답 노트 (AI Coding Mission & Wrong Answer Notes)

Gemini API를 활용하여 매일 프로그래밍 언어별, 난이도별 맞춤형 실전 코딩 테스트 문제를 제공받고, 이를 캘린더 형태로 기록 및 복습할 수 있는 **웹 기반 개인 학습 관리 애플리케이션**입니다. 단순 개념 질문을 지양하고 변별력 있는 소스 코드 분석 및 알고리즘 구현 문제를 중심으로 학습하도록 설계되었습니다.

## 🚀 주요 기능 (Features)

*   **🤖 AI 기반 맞춤형 문제 생성**: Gemini API(`gemini-2.5-flash`)를 연동하여 실시간으로 정밀한 코딩 테스트 문제를 출제합니다.
*   **⚙️ 다국어 및 난이도 설정**: 
    *   **지원 언어**: JavaScript, Python, Java, C++, TypeScript
    *   **난이도 조절**: 쉬움(기본 문법), 보통(실무 및 알고리즘 기초), 어려움(심화 개념 및 에지 케이스)
*   **📅 대시보드 & 통계 캘린더**: 
    *   날짜별 풀이 이력을 한눈에 볼 수 있는 그리드형 달력 기능을 제공합니다.
    *   통합 성공률 및 총 풀이 문항 수 통계를 실시간으로 계산하여 시각화합니다.
*   **🚨 스마트 오답 노트 및 필터링**: 
    *   틀린 문제는 오답 노트를 통해 라인별 분석 해설을 다시 확인할 수 있습니다.
    *   '숙지 완료' 처리 시 취약 문항에서 제외할 수 있으며, 언어·난이도별 필터링 기능이 포함되어 있습니다.
*   **📂 나만의 명품 문제 보관함 (⭐)**: 기억하고 싶거나 완성도 높은 문제를 별도로 보관할 수 있는 스토리지 기능을 지원합니다.
*   **💾 LocalStorage 기반 데이터 보존**: API 키, 학습 이력, 개별 문제 메모 등이 사용자의 브라우저에 안전하게 로컬 저장됩니다.

## 🛠️ 기술 스택 (Tech Stack)

*   **Frontend**: HTML5, CSS3 (Flexbox/Grid, Responsive Design), Vanilla JavaScript (ES6+)
*   **AI Engine**: Google Gemini API (`gemini-2.5-flash`)
*   **Libraries**: Prism.js (Tomorrow Theme - 다양한 언어의 소스 코드 구문 강조/Syntax Highlighting)

## 📦 시작하기 (Getting Started)

본 프로젝트는 별도의 서버 구동 없이, HTML 파일을 브라우저에서 여는 것만으로 즉시 사용할 수 있는 단일 페이지 애플리케이션(SPA)입니다.

1. 이 저장소를 클론하거나 HTML 소스코드를 다운로드합니다.
```bash
   git clone https://github.com/samdaso1739/-.git
```

2. index.html 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari 등)에서 실행합니다.

3. 상단 설정 창에 본인의 Gemini API Key를 입력하고 [저장] 버튼을 누릅니다.

4. 원하시는 프로그래밍 언어와 난이도를 선택한 뒤 [오늘의 코딩 테스트 가져오기]를 눌러 학습을 시작하세요!

## 📸 주요 화면 구성 (UI Components)
설정 및 API 영역: API 키 관리 및 타깃 언어, 난이도 조절 창

오늘의 미션 영역: Prism.js가 적용된 코드 스니펫과 객관식 선지 및 실시간 정답/오답 피드백 화면

통계 및 캘린더 영역: 월별 네비게이션, 언어/난이도 필터링 드롭다운, 당일 풀이 결과(정답/오답/완료) 배지 표시 시스템

복습 모달 창: 개별 문제 메모 기록 기능, 정밀 분석 해설 제공, 보관함 등록 및 숙지 완료 처리

## 💡 유의 사항
본 애플리케이션은 순수 클라이언트 사이드 코드로 동작하므로, 브라우저의 쿠키 및 사이트 데이터(LocalStorage)를 삭제하면 학습 이력이 초기화될 수 있습니다.

Gemini API 요청 제한(RPM)을 초과한 경우(에러 코드 429), 약 1분 뒤에 다시 시도해 주세요.
